## 📂 Using the application

When you open ZimReader, the interface shows a clean search bar. Type your topic into the box and press Enter to see results. The application displays articles in a clear format. 

You can open multiple articles at once using the tab bar at the top of the window. Click the plus icon to create a new tab. This helps you keep research organized. 

To use the wikirace mode, click the menu button and select the game option. The application challenges you to navigate from one article to another using only the links inside the text. 

## 🛠️ Managing offline files

ZimReader requires a ZIM file to show content. These files act as archives for Wikipedia data. You can download these large files from the Internet Archive or the Kiwix website. 

1. Download a ZIM file from a trusted source.
2. Open ZimReader.
3. Choose the Open File option from the File menu.
4. Select the ZIM file you downloaded.
5. The application loads the content and makes it ready for search.

## 🔍 Frequently asked questions

**Do I need an internet connection to run the software?**
No. You only need the internet to download the application and the ZIM data files. Once you store these files on your hard drive, you can read everything offline.

**Why is the search slow?**
The search speed depends on the size of the ZIM file. Large archives contain millions of pages. The application indexes these pages when you open the file for the first time. Please wait a moment during this process.

**Can I change the look of the app?**
ZimReader follows the theme of your system. If you use a dark mode in your Windows settings, the application automatically adjusts its colors to match.

**Is this software free?**
Yes. ZimReader is open source and does not cost money to download or use.

**Where can I find more files?**
The Kiwix website maintains collections of ZIM files for various languages and topics. You can download versions of Wikipedia that cater to specific interests or subject areas.

## 🛡️ Privacy and safety

This application does not collect your data. It does not track your searches or your reading history. All information stays on your local computer. Since you provide the data files yourself, you control what information exists within the software. 

## 📈 Troubleshooting

If the application fails to start, check that you downloaded the setup file for your operating system. Ensure your antivirus software allows the application to run. Some systems require you to click More Info during the installation process to bypass security warnings for new software.

If the library does not load, verify that the ZIM file is not corrupt. Try redownloading the file if it stops during the process. Large files sometimes experience interrupted connections. Use a download manager if you have a weak internet connection.
